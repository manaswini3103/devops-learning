# MAN
- opens manual pages
- you can type man and then any command to get to know more about it.
- Ex: man ls
it tells what “ls” will do and its options
- Even help (ls --help) does the same thing.
- But if we don’t know the command we are looking for, we can use the program called “apropos”.
  **ex:** apropos list
  it will give all the commands related to list
