# Read file commands
- ls – lists the files.
    - ls -lrt
    - l - long list,t - first display the file name which was created/updated recently, r - display the sequence in reverse.
- cat, head, tail
ex:
cat filename.txt (display the content of file)
head -10 filename.txt (displays first 10 lines of the file.)
tail -10 filename.txt (displays the last 10 lines of the file.)
- less/more (commands displays the file page by page. will type space key to move to next page.)
