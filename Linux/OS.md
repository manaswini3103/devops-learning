# Operating System (OS)

- An Operating System (OS) is the main system software that acts as an intermediary between computer hardware and software/users.
- It performs critical functions such as process management, memory allocation, file handling, input/output operations, and security.
- It provides user interfaces like GUI (Graphical User Interface) or CLI (Command Line Interface) to interact with the system.
- It manages hardware resources, supports application programs, and ensures efficient task execution. Without an OS, using a computer or mobile device would be nearly impossible.

## Examples of Operating Systems
1. **Windows**: A widely used OS for personal computers, known for its GUI and compatibility with various applications.  
2. **Linux**: An open-source OS used for servers, desktops, and embedded systems.  
3. **macOS**: Apple’s OS for Mac computers, known for its design and security features.  
4. **Android**: A mobile OS developed by Google, primarily for smartphones and tablets.  
5. **iOS**: Apple’s mobile OS for iPhones and iPads, known for seamless integration with Apple devices.

# User Interface (UI)

A User Interface (UI) is how a user interacts with a computer or device. There are two main types.

## GUI (Graphical User Interface)

- GUI allows users to interact using visual elements like icons, buttons, scrollbars, pointers, and menus.
- It makes devices more user-friendly by enabling actions like clicking and tapping instead of typing commands.
- **Examples:** Windows, macOS, and interfaces on smartphones and tablets.

## CLI (Command Line Interface)

- CLI is a text-based interface where users interact by typing commands.
- It enables efficient program execution, file management, and system configuration.
- Preferred by developers and system administrators for its speed and scripting capabilities.
- **Examples:** Command Prompt and PowerShell (Windows), Bash (Linux), Terminal (macOS).
