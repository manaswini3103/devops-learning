# Compiled Languages
A compiled language is translated all at once into machine code before execution using a compiler.

## How it works

- You write source code.
- A compiler converts the entire program into an executable file.
- The executable is run by the operating system.

## Characteristics

- Faster execution (already in machine code)
- Errors are reported before the program runs
- Platform-dependent executables (often)
- Requires a compilation step
- Examples: C, C++, Rust, Go

## flow
Source Code → Compiler → Executable → Run


# Interpreted Languages
An interpreted language is translated line by line at runtime by an interpreter.

## How it works

- You write source code.
- An interpreter reads and executes each line directly.
- No separate executable file is created.

## Characteristics

- Slower execution (translation happens during runtime)
- Errors appear while the program is running
- More portable across platforms
- Easier for rapid development and debugging
- Examples: Python, JavaScript, Ruby, PHP

## flow
Source Code → Interpreter → Output
