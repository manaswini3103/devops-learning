# Body	

- It contains the content, the message that we want to send or that comes back from the server. 
- So, the body is part of the request message as well as the response message.
- Content of Body: text, images, video, sound,  ..
- When working with APIs most of the time we send and receive message containing text.
- Not all requests have a body – only POST, PUT and PATCH requests have body.
- Most responses contain a body
