## API Documentation

API documentation typically includes:

- **Endpoints**
- **Resources**
- **Data types**
- **HTTP methods**

---

## Types of REST API Documentation (Mostly Informal)

- HTML / PDF documentation  
- Postman collection (`.json` file)  
- Postman documentation (Run in Postman button)  
- Swagger documentation  
- Standard specifications:
  - OpenAPI
  - RAML
  - OData
  - …

---

## How to Find API Documentation

Search using:  
`<service name> + API`  
`<service name> + developer`  

### Examples

- Google Image Search API  
- Twitter API  
- GitHub Jobs API
