# Git

It is a **Distributed Version Control System**, which is a tool that helps to track changes in code.

- It is free and open source
- It is fast and scalable
- It is a command-line tool installed locally on your computer.
- Git's primary function is to track changes in files and coordinate work among multiple developers on a project.
- It tracks the entire history of the project, when a file is added or deleted, which line is updated in code etc.

## Key features include

1. Version Control:  
Git records the history of changes made to files, allowing you to revert to previous versions, compare changes, and understand who made what modifications.
2. Branching and Merging:  
It enables developers to create separate branches of code to work on new features or bug fixes independently, then merge these changes back into the main codebase.
3. Local Repositories:  
Git stores the entire project history locally on each developer's machine, providing offline access and faster operations.

# GitHub

- GitHub is a web-based platform that provides hosting for Git repositories.
- It builds upon Git's functionality by offering a centralized location for collaboration and project management.
- GitHub is a service, not a tool, and is owned by Microsoft.
- It is a website that allows developers to store and manage their code using GIt.
- We can upload the entire code of our project in form of a folder. These folders are calles a **Repository**.
- We can see the Repositories of other people, copy and make our own changes.
- It's official website is `https://github.com`

## Its features include

1. Remote Repository Hosting:  
It allows developers to store their Git repositories on a central server, making them accessible to a team and enabling remote collaboration.
2. Collaboration Tools:  
GitHub offers features like pull requests for code review, issue tracking for managing tasks and bugs, and project boards for organizing workflows.
3. Social Coding:  
It facilitates community interaction, allowing developers to discover projects, contribute to open-source initiatives, and showcase their work.
